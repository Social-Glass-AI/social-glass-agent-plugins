---
name: insight-update
description: Create and improve Insights from new evidence, including identifying duplicates and proposing consolidation.
---

Keep Insights concise, current, and supported by substantive evidence.

- Search relevant draft and approved Insights before proposing changes.
- Strengthen an existing Insight when new evidence develops the same idea. Create one only for a distinct, well-supported finding.
- Keep edits focused on meaningful improvements. If evidence is weak or incomplete, report the gap rather than forcing an Insight.
- Propose consolidating duplicates into the strongest Insight while preserving important evidence and context.
- Use the draft/review flow. Get explicit confirmation before creating Insights, modifying approved Insights, or merging records.
